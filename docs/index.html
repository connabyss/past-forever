Past Forever

A language where a loop can run forever, and the program carries on afterwards. It only says a number settled when it can prove it.

Words it knows
  • x = 5 gives a name a number. count n = 0 makes a count that can go past forever.
  • forever: x = x × x runs the rest of the line without end. Lines pushed in below it work too.
  • show x, show 40 digits of x, and why x for the reason.
  • if x ends in 7: found = yes, with else:. Also is even, is odd, is a palindrome, =, <, >.
  • + − × /, powers like x^5, and mod, backwards(x), digitsum(x), repeat 10:, and forever as a number for counts.
  • hunt c from 0 to 99: runs the lines pushed in below it once for every number, and sorts the numbers by what their last show said. Tap a square to open that one loop. Add ends in 57 before the colon to look only at numbers ending in 57 (that is what Zoom in does). Rings and liars are checked 40 digits deep.
  • You can divide by anything that has no 2 or 5 in it. There is no one half here.
