The last 360 digits of Graham's number, as music

Graham's number is too big to write down. Its last digits never change, though, so this loop can work them out:

x = 3
forever: x = 3 ^ x
sing 360 digits of x

Each hole is one digit, starting from the last. Further right, higher note.

one minute, turn the sound on

Past Forever is a tiny language where a loop can run forever and still hand you an answer. Try your own loop.
